| 2026-11-08 | Manage Python dependencies with `uv` (`pyproject.toml` plus `uv.lock`), with `package = false` until Stage 0 creates `tinytalk/`. `requirements.txt` is now superseded and left in place for now. | Keep the `pip freeze` `requirements.txt`. | The lock file records exact versions for reproducing results. `uv` also replaced the unfinished `wrapt==2.6.0.dev1` pin with `wrapt==2.5.2`. |
| 2026-11-08 | `pystoi` and `audiomentations` are an optional dependency group `audio`. `pesq` is not installed. | Adding `pesq` to the main dependencies. | `pesq==0.0.4` failed to build here: `fatal error C1083: Cannot open include file: 'io.h'` (the Windows SDK headers are missing). One fix would be installing the Windows SDK. Objective Tier A scores use `pystoi` only until then. |
| 2026-11-08 | No `num2words`. Number words for Hindi and Malayalam come from our own tables. | `num2words`. | It has no Hindi or Malayalam support (tested v0.5.14, as reported by Yadhu; not re-tested by me). |
| 2026-11-08 | Added `tests/test_codec_smoke.py` so `make check` and CI have one real test. | An empty `tests/` folder. | `pytest` exits with an error when it finds no tests, so the empty skeleton would fail the Stage 0 gate. |
| 2026-11-08 | Wrote `docs/NORTH_STAR.md` as a DRAFT from `CLAUDE.md` and the playbook, and created 11 empty modules from it. | Stopping to wait for Yadhu to supply NORTH_STAR. | The file was missing and Stage 0 needs it. A labelled draft keeps work moving and is easy to replace. |
| 2026-11-08 | Left seeds, voices, credit cap and STT concurrency as `null` in `config.yaml`. | Picking values myself. | The sources do not give them. A guessed seed or cap would look like a decision when it is not. |
| 2026-11-08 | Installed GNU Make with `winget install ezwinports.make`. Pytest uses `pythonpath = ["."]` and `pyyaml` was added as a direct dependency. | A PowerShell script instead of `make`; installing `tinytalk` as a package now. | The playbook's gate names `make check`. Packaging can wait until a stage needs it. |
| 2026-11-08 | `tinytalk/gnani.py` calls Gnani's REST endpoints with `httpx` (not the `gnani-vachana` SDK) and writes the ledger as plain JSON lines (not `structlog`). | The SDK (uses `requests`, harder to fake in tests); `structlog` for the ledger. | `httpx` plus `respx`/`MockTransport` gives a fake transport for tests with no network. A JSON line per call is all the ledger needs. Request shapes were copied from the SDK source. |
| 2026-11-08 | A `null` `credits.max_calls` means no live calls are allowed. The cap counts HTTP attempts (retries included) and is read back from the ledger, so it holds across runs. | Treat null as unlimited; count only successful calls. | Protects credits from a missing setting. Retries may be billed. |
| 2026-11-08 | Working mode: no stage gates, plan files or approval waits (Yadhu's instruction). Process rules in `docs/BUILD_PLAYBOOK.md` that slow building are overridden; see `CLAUDE.md`. | Following the playbook's gates strictly. | Deadline is Tue 10 Nov 23:59 IST. |
| 2026-11-08 | Aligned `tinytalk/gnani.py` with the Gnani docs: form field `keyterms` (the SDK sends `keywords`), one lock for STT and TTS together, three attempts with 0.5 s to 2 s backoff, retry on connection errors, ledger also records `end_to_end_latency` and `truncated`. `concurrency.stt` set to 1. See `docs/GNANI_NOTES.md`. | Copy the SDK exactly; five attempts; TTS-only lock. | Docs say one active request per account for all services and advise three attempts. More attempts could burn credits. |
| 2026-11-09 | Corpus: 40 parallel fact sets (10 each of flood, boats, supply, medical), rendered in Malayalam, Hindi and English with fixed templates; 12 dev and 28 test messages chosen by seed 1108, same split for every language. 12 Kerala places. Other seeds: link 2026, bootstrap 7. | A separate fact set per language; free-form sentences. | Parallel facts allow comparing languages directly. Templates keep every fact known exactly. Seeds were not given, so I picked them and wrote them down. |
| 2026-11-09 | Fact parser matches places by name substring, units by word beginnings (Malayalam adds endings to words), hours only with am/pm/बजे/മണി plus a period word. Number words: English 0-99, Hindi 1-99, Malayalam 1-20 and tens (compound Malayalam numbers are not covered). | `rapidfuzz` fuzzy matching (against CLAUDE.md rule); `num2words`. | Exact matching keeps scoring honest. Prisma's `transcribe` format already returns digits, so word tables are a fallback. |
| 2026-11-09 | Tier B packs transcripts with a place codebook, binary numbers and a zstd raw-content dictionary made from the 12 dev messages. | A trained zstd dictionary (12 samples are too few to train one); plain zstd. | A dictionary of raw dev text needs no training and never sees the test split. |
| 2026-11-09 | Tier picker rule (config `tier_picker`): audio if loss is at most 10 percent and the link carries 2400 bps live; else transcript if its airtime is at most 10 s; else facts only. | A learned picker; the reliability estimator (Stage 8). | Simple, explainable rule. The thresholds are my choice and not tuned on data. |
| 2026-11-09 | Link loss is bursty (Gilbert-Elliott, mean burst 3 packets), packets are 48 bytes plus 4 bytes header (sequence number and CRC16), up to 3 resends for Tier B and C, none for Tier A. | Independent random loss. | CLAUDE.md asks for bursty seeded loss. The packet size and burst length are my choices. |
| 2026-11-09 | Decoded Tier A audio is stored in the cache on first use. | Re-decoding each run. | The Codec2 decoder adds random phase, so each decode is different and would make Prisma cache keys miss and waste credits. |
| 2026-11-09 | Live runs need an explicit `--live --max-new-calls N`; the default is a free dry run. | Using `credits.max_calls` alone. | Credits are limited (about 4.9k left, reported by Yadhu). |
| 2026-11-09 | API in LIVE mode needs a token and uses one shared client; web UI has no voice recording; teach-back in the UI compares text, voice teach-back is not built. | Open live endpoint; browser recording. | Found by the automated security review: separate clients would bypass the call cap. Recording and voice teach-back would cost credits and time. |
| 2026-11-09 | MIT license, copyright holder `yaadhuu`. | Other licences. | Playbook asks for a LICENSE; MIT is the simplest. Change the name if you prefer. |
| 2026-11-09 | Malayalam stays a full language. Rule: at least 85 percent exact facts in the pilot. Pilot: 0.871 (27/31) before and 1.0 (31/31) after a parser fix, on 10 messages. See E3. | Dropping Malayalam to a smaller role. | The rule is met. Caveat: only 10 messages, and the parser fix was made on those same dev messages. |
| 2026-11-09 | Parser fix: Malayalam unit stems stop before the final chillu letter; added English variant "Chalakudi". No spelling variants added for real Prisma errors (Itachi, सालाकुड़ी, अलग पूजा). | Adding every heard spelling to the gazetteer. | Wrong place names are real recognition errors and must count as failures. A joined Malayalam word is a parser gap. |
| 2026-11-09 | `pycodec2` is wrapped frame by frame in `tinytalk/codec.py` (encode and decode one 160-sample frame at a time). | Calling `Codec2.encode` and `decode` on a whole array. | The library only handles the first frame per call; the first Tier A run was invalid because of it (E5). The 2026-11-08 decision to use pycodec2 stands, but its check was too weak. |
| 2026-11-09 | Main run scope: test split, 1 voice (Vasudha), speed 1.0, conditions off and both; tiers at link 5 kbps with loss 0, 10, 20 and 30 percent. Not run: other voices and speeds, Prisma v2.5, `transliterate`, estimator, voice teach-back. | The full 3 voices x 3 speeds grid. | Credit limit (about 4.9k reported before the pilot). 987 live attempts used in total, see COSTS. |
| 2026-11-09 | UI direction: a calm "link console", cool paper and harbour-ink palette, tier colours that mean the same everywhere (amber audio, blue transcript, green facts), Geist for text with Noto Sans fallbacks for Malayalam and Devanagari, Geist Mono for numbers. One memorable element: a packet strip per tier. | The generated "cyberpunk" style from the design search; a cream/serif look; a generic dashboard of equal cards. | The first suggestion (neon terminal) does not fit a humanitarian tool and was rejected. The packet strip shows the whole idea (audio breaks, one packet of facts survives) in one glance. |
| 2026-11-09 | Link settings are fixed choices (2, 5, 10 kbps; 0, 10, 20, 30 percent) in keyboard-friendly radio groups, and changing them re-sends the message at once. The page opens with an example already sent. | Free sliders; a send-only flow; an empty start. | The simulator was only validated at these levels. Immediate response makes cause and effect visible. |
| 2026-11-09 | Added `@fontsource-variable/geist-mono` (numbers) and the API now returns per-packet states (ok, resent, lost). | Drawing only totals. | Needed for the packet strip. Per CLAUDE.md, new library logged here. |
| 2026-11-09 | Stage 11 web product: React Router, 9 pages plus 404, one `DataSource` (static Replay files exported from real results, or the live API). The Replay edition uses hash URLs and works offline from a clean clone. | Building against hand-written fixtures; a server-only app. | The brief requires real saved results, never mocks, in the final build. |
| 2026-11-09 | Design: field manual and radio-room panel (paper #F4ECDB, ink #171A2E, vermilion #B3321F, teal #0F5C5A, turmeric darkened to #A06B10 for AA, gold #B8892B for rules only), Fraunces / Rozha One / Noto Serif Malayalam for display, Anek for text, IBM Plex Mono for numbers, custom SVG dial, VU gauge, stamped tier cards, d3-scale/d3-shape charts. | Full `d3` (only scale and shape are used); lucide icons (no stock icons per brief). | Contrast checked by script; `d3-scale` and `d3-shape` are the parts of d3 we use. |
